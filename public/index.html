Setup

Four steps connect your controller to Live. Each turns green as it's done.

  1. 1

    Install AbletonOSC

    checking…

    AbletonOSC lets this app talk to Live. It's bundled in — install it into Ableton's Remote Scripts folder.

    Running in a browser, so install manually:

    1. Download AbletonOSC.
    2. Copy the AbletonOSC folder into Live's User Library/Remote Scripts/ folder.
  2. 2

    Restart Ableton Live

    manual

    Live only scans for Remote Scripts when it launches. Quit and reopen Live (or open it now if it's closed).

  3. 3

    Enable the Control Surface

    waiting…

    In Live: Settings → Link, Tempo & MIDI → MIDI. Under Control Surface, pick AbletonOSC (Input/Output = None). Live's status bar will read “AbletonOSC: Listening for OSC on port 11000.”

    Turns the Ableton light green automatically.
  4. 4

    Connect your controller

    waiting…

    Plug in your MIDI controller, close this guide, add a control, hit Learn, and move a knob or fader.
